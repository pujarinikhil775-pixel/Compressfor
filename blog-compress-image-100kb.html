Common Mistakes People Make When Compressing Images

We see these patterns repeatedly and they are worth knowing about before you start:

Compressing the Same Image Multiple Times

Every time you compress a JPG it loses a little more quality because of how JPEG compression works. Always compress once from the original high resolution photo. Never from a previously compressed version.

Choosing PNG Instead of JPG

PNG files are significantly larger than JPG at the same image dimensions and resolution. If your portal accepts JPG always use JPG. A PNG compressed to 100KB will look noticeably worse than a JPG compressed to the same size because PNG has to sacrifice much more quality to reach that file size.

Compressing Screenshots Instead of Original Photos

Screenshots are already compressed in a way that makes further compression very lossy. Always start from the original high resolution photo for the best possible result.

Uploading Photos Already Shared on WhatsApp

WhatsApp automatically recompresses images when you send them. A photo received on WhatsApp has already lost quality once. Starting from a WhatsApp image and compressing again degrades it twice. Always use the original camera photo.

Ignoring the Format Requirement

Most portals specifically require JPG or JPEG format. Uploading a WebP or PNG file even if it is under 100KB may still be rejected because of the wrong file format. Always check the format requirement alongside the file size upload limit.

Resize Image to 100KB — Compression vs Resizing

People often ask whether they should resize or compress to hit the 100KB upload limit. Here is a clear comparison:

  • Compression only — reduces file size by removing image data while keeping the same pixel dimensions and resolution. Works well when the original is not much larger than 100KB. Quality suffers as you push it harder toward smaller sizes.
  • Resizing only — reduces pixel dimensions which directly reduces file size. Keeps better quality per pixel but makes the image physically smaller in resolution.
  • Both together — the most effective approach for image optimization. Slightly reduce dimensions to make compression easier then apply quality compression to hit the exact 100KB target.

CompressFor uses both together automatically. It first tries compression only. If that cannot reach your target without unacceptable quality loss it also reduces image dimensions slightly. The result is the best possible quality at exactly your target file size.
